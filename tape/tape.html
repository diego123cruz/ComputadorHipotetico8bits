Como funciona o protocolo (referência)

Mesma codificação usada no carregador de fita k7.z80: dois tons, 1 kHz e 2 kHz. Cada bit é uma sequência de ciclos das duas frequências, sempre com a mesma duração total (6 ms) — só muda a proporção entre elas:

bit 08 ciclos @2kHz + 2 ciclos @1kHz
bit 14 ciclos @2kHz + 4 ciclos @1kHz

Cada byte é enviado como no formato serial clássico: start(0) + 8 bits de dado (LSB primeiro) + stop(1) — 10 bits = 60 ms/byte.

Estrutura completa do áudio:

Leader (sincronismo)4000 ciclos @1kHz (~4s)
Cabeçalho7 bytes: título(2) + endereço inicial(2) + endereço final(2) + checksum(1)
Gap2000 ciclos @2kHz (~1s)
Dadosbytes do endereço inicial ao final, inclusive
Trailer4000 ciclos @2kHz (~2s)

O checksum é a soma (mod 256) de todos os bytes de dados enviados.

Importante: esta página só gera e toca o áudio (é a "gravação/transmissão"). Para o Computador Hipotético 8 bits carregar o programa de volta, o firmware do Arduino precisa de uma rotina de leitura equivalente a PERIOD/LEBIT/LEBYTE do k7.z80 — ainda não implementada neste projeto.
